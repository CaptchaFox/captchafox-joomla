# CaptchaFox for Joomla

Official [CaptchaFox](https://captchafox.com) captcha plugin for Joomla.

> **Status:** in development, no release yet.

## Compatibility

| Joomla | PHP |
|---|---|
| 5.4 or later | 8.1 or later |
| 6.x | 8.3 or later |

Joomla 3, 4, 5.0–5.3 and 7 are not supported.
